# Doubtful claims found on the live storefront, and what changed in this preview

Look and colours are unchanged. Only wording that could not be backed up was removed or replaced with a confirmation, not a new promise.

1. Title: "Curated Luxury Store & Global Shipping"
   Removed the global shipping claim. Now: "Curated Store".

2. Meta description: "…and global express shipping."
   Removed. Description no longer mentions shipping speed or worldwide delivery.

3. og:description: "…reliable worldwide shipping."
   Removed the shipping claim.

4. Brand subtitle: "Curated Global Store"
   Now: "Curated Store".

5. Hero headline: "Delivered Worldwide."
   Removed. Now: "For the journey ahead." (travel focus, not a delivery promise).

6. Hero body: "…vetted for quality and shipped globally."
   Removed "shipped globally" and the quality-vetting claim. Now describes the current placeholder range without those promises.

7. Perk: "Worldwide Express Shipping"
   Removed. Replaced with a real offer: "Cash on Delivery in Bangladesh".

8. Perk: "Curated Quality Guarantee"
   Removed. No guarantee policy exists. Not replaced with a new guarantee.

9. Product p4 badge: "Global Ready"
   Removed the implied worldwide-ready claim. Now: "Travel".

10. Cart bar: "You unlocked Free Global Express Shipping!" and "Add $X more for Free Global Express Shipping"
    Removed entirely. No free worldwide shipping offer exists.

11. Checkout title: "Express Checkout"
    "Express" could be read as express shipping. Now: "Checkout".

12. Shipping method option: "Worldwide Express"
    Removed. Country list no longer includes a worldwide-express option.

13. Confirmation: "Order Confirmed" and "Your curated order has been registered with BrandLinker Spark fulfillment."
    Replaced with a truthful message: the order is saved, a real order ID is shown, and "we will contact you to confirm." No fulfilment claim.

14. README: "global express checkout"
    Removed.
